# Archita Srivastava — Personal Website

## Put it online with GitHub Pages (free)

1. Go to github.com → click **+** (top right) → **New repository**.
2. Name it exactly **`<your-github-username>.github.io`**. Set it to **Public** → **Create repository**.
3. On the new repo page, click **uploading an existing file**.
4. Drag in **`index.html`**, the **`images`** folder and the **`slides`** folder → **Commit changes**.
5. Go to **Settings → Pages**. Under "Branch", pick **main** and **/ (root)** → **Save**.
6. Wait 1–2 minutes, then visit **https://<your-github-username>.github.io**

## Editing later
- **Photos:** add files to `images/` using the names in `images/README.md`.
- **Presentations:** add PDFs to `slides/` using the names in `slides/README.md`. Their buttons appear automatically.
- **Other links** (LinkedIn, GitHub, Scholar, paper, videos): in `index.html`, search for `href="#"` and paste the real link between the quotes. Unfilled links stay hidden.
- **Text:** edit words directly in `index.html` (on GitHub: open the file → pencil icon → Commit).
